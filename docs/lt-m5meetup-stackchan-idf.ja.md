# LT: yet another ｽﾀｯｸﾁｬﾝ ファームウェア「stackchan-idf」

- 場: M5Stack User Meetup
- 持ち時間: 5分
- 題材: stackchan-idf (ESP-IDF 5.5 / C++20 製の独立系ｽﾀｯｸﾁｬﾝ ファームウェア)
- 想定スライド枚数: 10〜11枚 (1枚あたり約30秒)
- 聴衆の前提: M5Stack ユーザ。ｽﾀｯｸﾁｬﾝ自体は既知として説明は最小限。公式ファームや
  AIｽﾀｯｸﾁｬﾝを知っている人が多い前提で「何が違うか」に時間を使う

> 構成方針: 前半で「公式とは別物の、もう一つのファーム」と立ち位置を明確にし、
> 中盤で **公式にない差別化要因** (ブラウザ書き込み / 無線設定 / OTA / 顔の差し替え /
> オンデバイス TTS) を 1 枚 1 機能で畳みかけ、後半で「同じ 1 コードベースが 4 ボードで
> 動く」→ 小ネタ (ESP-NOW 公式リモコン互換・ダンス) → 誘導、で締める。
> AI 対話機能は公式にもあるので **差別化としては前面に出さない** (「もちろんある」程度)。

## 2. 全体像 (30秒 / 1枚)

### スライド: アーキテクチャ

- `docs/architecture.drawio` を流用 (矢印なしの階層図)。HW 枠 = M5StackChan、
  点線枠 = stackchan-idf
- 層: Transports (BLE / HTTP / SoftAP / ESP-NOW) → Services (設定・OTA・会話) →
  App tasks (Render / Servo / Conversation / Audio) → Engines (Avatar / TTS / ASR) →
  HAL (M5Unified / SCS servo / board)
- 口頭: 「FreeRTOS の 2 コアにタスクを割り振った、普通の ESP-IDF アプリです」
- 数字を 1 つだけ: 顔描画 **30 fps** (breath / saccade / blink)

---

## 3. 差別化その1: ブラウザから書き込み (30秒 / 1枚)

### スライド: IDE 不要、URL 開いて Flash

- <https://ciniml.github.io/stackchan-idf/> を Chrome/Edge で開く → ボード選択 → Flash
- Web Serial 経由。CI が `vX.Y.Z` タグで **4 ボード分**をビルドして GitHub Pages に配置
- **スクショ: Web Flasher の画面** (ボード選択プルダウンが見える状態)
- 口頭: 「人に配るときに『Arduino IDE 入れて…』が要らない」

---

## 4. 差別化その2: 無線で設定 (BLE / Wi-Fi / SoftAP) (40秒 / 1枚)

### スライド: ケーブル無しで全部設定

- 3 経路を 3 カラムで:
  - **BLE**: Web Bluetooth の `settings.html`。**X25519 鍵交換 + AES-256-GCM** で
    アプリ層暗号化 (OS ペアリング不要)
  - **Wi-Fi**: 機体の HTTP サーバ + mDNS (`stackchan-XXXXXX.local`)
  - **SoftAP + キャプティブポータル**: 未設定時は AP を立てて LCD に **Wi-Fi QR**。
    iPhone のカメラで読むと設定ページが勝手に開く
- 設定できるもの: SSID / AI プロバイダ / API キー / システムプロンプト / サーボ可動域 /
  音声 / 顔 / 動作モード
- **写真: LCD の QR コードを iPhone で読んでいるところ** (現物感)
- 小ネタ (時間があれば): 検証用に Rust で BLE CLI も作った (`tools/ble-cli`)

---

## 5. 差別化その3: OTA (30秒 / 1枚)

### スライド: 機体が自分で GitHub から更新を取ってくる

- デュアル OTA パーティション + 起動検証 + **自動ロールバック**
- 3 経路: BLE チャンク / Wi-Fi で `.bin` アップロード / **機体側フェッチ**
  (`POST /api/ota/release {tag}` → 自分のボード用バイナリを GitHub Pages から取得)
- 口頭: 「Web Flasher と同じ成果物を使うので、書き込みと更新で経路が分かれない」

---

## 6. 差別化その4: 顔を書き換えなしで差し替え (40秒 / 1枚)

### スライド: 顔はコードじゃなくてデータ

- 設定ページから 目 / 眉 / 口 の形と色を変更 → 即反映
- 丸ごと差し替え: **Avatar DSL** (`.avdsl` ソース → `.avbc` バイトコード) を
  BLE / Wi-Fi で送ると、レイアウトもアニメも **ライブで切り替わる**。NVS に保存され再起動後も維持
- **Before / After の 2 枚の顔スクショ**を並べる (デフォルト顔 → カスタム顔)
- 口頭: 「ファーム再ビルド無しで『自分のｽﾀｯｸﾁｬﾝ』にできる」
- DSL の断片を 3〜4 行だけコード枠で見せると「ほんとに DSL なんだ」感が出る

---

## 7. 差別化その5: オンデバイス日本語 TTS (30秒 / 1枚)

### スライド: クラウド無しでも喋る

- **HMM ベース日本語 TTS** (HTS `.htsvoice` + MLSA ボコーダ) を ESP32-S3 上で動かした
- 用途: 待機中のひとりごと、ウェイクワードへの「はい」、タイマー読み上げ
- 苦労話を 1 つだけ (数字付き):
  - 48 kHz → **16 kHz にオフラインでモデル変換して MLSA ~3 倍速 = リアルタイム**達成
  - 内部 RAM が逼迫して httpd/BLE が不安定になった → 16 MB ボード専用・PSRAM 寄せ
- 「AI 対話 (OpenAI Realtime / Gemini Live / XiaoZhi) ももちろんあります」はここで
  一言だけ添える

---

## 8. 1 コードベースで 4 ボード (30秒 / 1枚)

### スライド: 手元の M5Stack で選べる

- 4 構成を写真付きで横並び:
  - **CoreS3** ｽﾀｯｸﾁｬﾝ (M5 公式キット / タカヲ版)
  - **AtomS3R + Atomic Echo Base** → アトムニャン
  - **M5 StopWatch (C152)** → 丸 AMOLED 顔
  - (オプション) わしし氏 **ネコミミ** (NeoPixel, GPIO9)
- 起動時にボード自動判別、無い機能はグレーアウト
- 口頭: 「サーボが無い機体でも顔+声+LED として動く」

---

## 9. 小ネタ (30秒 / 1枚)

### スライド: 最近足したもの

- **ESP-NOW 公式リモコン互換受信** (公式リモコンで首が動く) + **Sender モード** で
  2 台のミラーリング。公式リモコンが無かったので AtomS3 Lite でブリッジ機を自作して検証
- **ダンス**: フラッシュ上の音声 + キーフレーム (時刻 / 移動秒 / yaw・pitch %) で
  音楽同期の首振り。HTTP / BLE / 画面からトリガ
- **ウェイクワード ASR** (esp-sr WakeNet) — 自前 KWS は実験中
- 動画があればここで **10 秒のダンス動画** (生デモは 5 分では危険)
